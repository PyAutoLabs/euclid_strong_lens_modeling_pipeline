# wiki/project/

The memory for **this clone**: [`state.md`](./state.md) (the head pointer — where the work
got to, rewritten every session), the dated `YYYY-MM-DD-<slug>.md` journal entries (what
each session did, never rewritten), and [`profile.md`](./profile.md) (who you are working
with). The templates `_state_template.md`, `_profile_template.md` and `_template.md` are
the forms those three take.

The rest of the wiki — lensing concepts, literature, the how-to skills — is the
`autolens_assistant` clone's, not this repository's: refer back to it (see `AGENTS.md`,
"The assistant (skills + wiki)") rather than copying pages here.
